## 功能简介

- **四种计算模式**：按体重 `mg/kg/次`、`mg/kg/日`，按体表面积 `mg/m²/次`、`mg/m²/日`（Mosteller 公式）。
- **单位换算**：体重 `lb ⇄ kg`，身高 `inch ⇄ cm`，内部统一换算并实时显示。
- **液体制剂体积换算**：单次剂量 ÷ 制剂浓度 = 每次体积（mL/次），不自动四舍五入到量具刻度。
- **结果卡片**：输入信息、BSA、计算模式、人工录入参数、单次/每日剂量、液体体积、最大剂量比较、数据来源与审核状态、计算时间、完整计算过程、安全声明。
- **超限预警**：超过人工录入的单次/每日最大剂量时红色预警（图标+颜色+文字），**不自动截断结果**，展示原始结果、上限与差值。
- **完整计算过程**：可折叠面板逐步展示公式、单位变化与未提前舍入的原始值。
- **复制 / 打印**：复制内容包含安全声明与数据来源；打印版隐藏无关导航元素。
- **计算历史**：保存在浏览器 localStorage（不上传服务器、不含身份信息），支持查看、复制、删除（二次确认）、清空。
- **演示药物模板**：内置 8 个明显标注的**虚构演示数据**模板 + 空白模板；支持新增 / 编辑 / 删除自定义模板（强制填写来源与审核状态）。
- **真实药物导入库**：从开发者提供的院内参考资料（《儿科常用药物剂量整理》《儿科用药整理》《外科常用药物剂量和注意事项》《肿瘤外科住院医师入科培训及手册》等）摘录的 57 个常用药物模板，首次打开自动导入为**未审核**的自定义模板（可编辑、可删除、带来源记录，剂量区间取下限、完整原文区间见备注，支持一键核对后转「已审核」）。
- **模板分组与筛选**：计算页模板下拉框按「内置演示 / 院内资料 / 我的自定义」分组，模板页支持分类筛选与一键重新导入。
- **医疗安全设计**：结果统一称「数学计算结果 / 待复核结果」，禁用「推荐剂量 / 安全剂量」等表述；来源缺失、未审核模板显著警告；年龄不参与剂量推断；内置虚构演示数据与摘录的真实条目严格隔离（真实条目一律「未审核」+ 来源留痕）。
- **响应式界面**：电脑与手机浏览器均可用；简体中文；蓝绿色医疗风格。

## 技术栈

- React 18 + TypeScript（严格模式）
- Vite 5
- Tailwind CSS 3
- React Router（Hash 路由，可部署到 GitHub Pages 等静态托管）
- Vitest + @testing-library/react（纯计算函数与页面冒烟测试）
- localStorage（历史记录与自定义模板）

## 快速开始

环境要求：Node.js ≥ 18。

### 安装依赖

```bash
npm install
```

### 本地运行（开发模式）

```bash
npm run dev
```

启动后在浏览器打开终端提示的地址（默认 `http://localhost:5173`）。

### 单元测试

```bash
npm test          # 运行全部测试（68 项，含 15 类要求的计算/校验/安全标识 + 14 项页面冒烟测试）
npm run test:watch # 监听模式
```

### 构建项目

```bash
npm run build     # TypeScript 类型检查（tsc --noEmit）+ Vite 生产构建，输出到 dist/
npm run preview   # 本地预览构建产物
```

## 安全声明

**本工具仅用于教学演示和剂量计算复核，不能替代医生、药师判断，不可直接用于自行给儿童用药。**

- 本 Demo 展示的是剂量数学计算与复核流程，不构成诊断、处方或用药建议；
- 内置模板均为**虚构演示数据**，不可用于真实患者；
- 真实场景中的药物、剂量、适应证、禁忌证、最大剂量和制剂浓度必须依据最新权威药品说明书或临床规范，由具备资质的医生或药师审核；
- 不得仅凭年龄、体重或体表面积给出「可以服用」或「建议服用」的结论。
